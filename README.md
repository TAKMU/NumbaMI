This project objective is to create a method to calculate Mutual information as fastly as possible. To do that we did the following:
<ol>
  <li>Discretize first</li>
  
  <li>Calculate entropies</li>

  <li>Obtain MI with entropies</li>
</ol>

Please follow these steps:
<ol>
  <li>Create conda environment with environment.yaml</li>
  
  <li>Make pipeline.sh executable</li>
  
  <li>Add matrix counts to data</li>
  
  <li>Modify pipeline.sh to be able to read the matrix</li>
</ol>

Considerations> Right now the input accepts genes as rows.
